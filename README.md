# FrontSeat

FrontSeat is a tablet-first restaurant host, waitlist, reservation, and seating planner.

## Features

- Visual touch-friendly floor plan
- Fast walk-in waitlist and quick seating
- Smart table recommendations
- Reservation conflict awareness
- Server workload tracking
- Table timers, cleaning queue, and status flow
- Undo for common actions
- Light, dark, high-contrast, and large-text modes
- Offline-capable PWA with local persistence
- JSON backup and restore

## GitHub Pages

This repository is designed to deploy directly with GitHub Pages from the `main` branch root.
